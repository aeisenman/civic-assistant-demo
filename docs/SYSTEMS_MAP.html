Municipality Agent

Resident assistant for the City of San Diego. A chat turn is classified, routed to a model tier, answered from City records by tool calls and from policy text by retrieval, then written to a trace. A form or document in the chat starts a back-office workflow.

docker compose · 5 containers: web, api, db, seaweedfs, litellm ports 3001 / 8080 / 5433 / 8333 / 4000 one .env file selects the model provider AWS path: deploy/aws/up.sh, EC2 + instance role, scripted, not run

API

FastAPI · Python 3.12 · SQLAlchemy 2 async · asyncpg · uv · :8080
One chat turn, in order
1

Guards, then intake

Bounds, per-IP bucket, session cookie, turn and cost caps, a stream slot or 429. A file drop or a needs-info reply is a workflow turn, templated.

2

Classify

Small tier returns JSON: intent, confidence, complexity, secondary intents. Last 3 messages as context.

3

Select tier

Escalate when confidence < 0.6, complexity high, or a second intent. Else smart. Reason goes on the trace.

4

Profile

One per intent: system prompt, tool allow-list, KB topic. 7 intents.

5

Retrieve

pgvector cosine top 8 + full-text top 8, fused by reciprocal rank fusion, top 5 cited as [n].

6

Tool loop

At most 4 rounds. Repeated calls served from a per-turn cache. Any tool failure becomes an error the model can read.

7

Cite and trace

Citations mapped back to sources. One traces row: tier, model, tokens, latency, cost.

8

Stream

Server-sent events: status, tool, token, done, a heartbeat every 15 s. Only the final answer round reaches the resident.

State machine for permit, business tax, service request, STRO licence. Row-locked advance; worker claims rows every 3 s with SKIP LOCKED. Issue stores the certificate before the status commits.

Model layer

openai SDK · LiteLLM :4000 · Amazon Bedrock us-west-2

Client app/llm/client.py

The only module that calls a model. Speaks the OpenAI protocol to LLM_BASE_URL. Every call is tiered, timed, priced, and traced.

Gateway litellm

Maps tier aliases to Bedrock model ids. Drops parameters Bedrock rejects. Starts only under the aws compose profile.

Sources on disk

api/kb/*.md: 9 topic files, split by heading into 133 chunks and embedded at startup. api/seed_data/*.json: 40 addresses, 12 collection zones, 9 council districts.

Migrations app/db/migrations/

Plain SQL files applied in filename order under an advisory lock, tracked in schema_migrations, with down files and a rollback flag. The vector width is asserted at startup against EMBED_DIM.

Chunking rag/ingest.py

Each ### Q: FAQ block is one chunk. Prose under ## is packed into 1200-character windows with 150 of overlap, on paragraph boundaries. Every chunk text starts with its title and heading.

Volumes and reset

Bind mounts data/volumes/pg and data/volumes/seaweed keep state across restarts. backup.sh runs before every reset; restore.sh is the drill.
